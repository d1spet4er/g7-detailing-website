# G7 Detailing Center — concept site

Concept landing page for GARAGE 007 Detailing Center in Krasnodar.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- lucide-react icons

## Local development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing
- Replace demonstration Unsplash images with photos supplied or approved by G7.
- Confirm all prices, service descriptions, contact details and working hours with the studio.
- Add the studio's official social links and preferred booking channel.
- Configure hosting and a custom domain.
- Run `npm run build` before deployment.

This is a visual concept, not yet a production deployment. Price labels are explicitly marked as indicative where they need confirmation.
